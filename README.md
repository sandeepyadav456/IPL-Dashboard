# 🏏 IPL Data Analysis Dashboard

## 📌 Overview
This project presents an in-depth analysis of IPL (Indian Premier League) data using Microsoft Excel.  
It focuses on extracting meaningful insights through data cleaning, pivot tables, and interactive dashboards.

The dashboard helps users explore team performance, player statistics, and match trends in a simple and visual way.

---

## 🎯 Objectives
- Analyze team performance across seasons  
- Identify top-performing players (runs, wickets, strike rate)  
- Study match trends and winning patterns  
- Build an interactive and user-friendly dashboard  



## 📂 Dataset Information
- 📊 Format: Excel (.xlsx)  
- 📁 Data Includes:
  - Match details  
  - Team statistics  
  - Player performance  
  - dim Venue

## 🛠️ Tools & Technologies Used

- Data Visualization
